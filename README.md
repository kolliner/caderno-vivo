# Caderno Vivo

Um laboratório virtual interativo para explorar modelos biológicos em 3D, consultar fontes científicas e adicionar notas de pesquisa.

O primeiro modelo disponível é o **Physarum polycephalum**. A navegação permite observar sua rede tubular e aproximar-se das estruturas, conectando a exploração visual ao estudo.

- **Explorar:** navegar pelo organismo e consultar informações sobre suas estruturas.
- **Caderno:** registrar notas, perguntas, hipóteses e observações de pesquisa.
- **Fontes:** organizar e consultar referências para aprofundar o estudo.

[Acessar o laboratório virtual](https://kolliner.github.io/caderno-vivo/)

As notas são salvas no navegador utilizado. Os modelos visuais são representações esquemáticas em desenvolvimento.
